# 간단한 계산기 프로그램 (Calculator)

사용 목적과 환경에 맞게 바로 실행하실 수 있도록 **웹(GUI) 계산기**와 **터미널(CLI) 계산기** 2가지를 준비했습니다.

---

## 1. 웹 브라우저 계산기 (추천)
별도의 프로그램 설치 없이 브라우저(Edge, Chrome 등)에서 바로 열어 사용할 수 있는 미려한 디자인의 모던 계산기입니다.

### 실행 방법
- 작업 디렉토리의 [`index.html`](file:///c:/Antigravity/Test1/index.html) 파일을 더블 클릭하여 웹 브라우저에서 바로 열 수 있습니다.
- 또는 터미널에서 다음 명령어로 열 수 있습니다:
  ```powershell
  Start-Process .\index.html
  ```

### 주요 기능
- **기본 사칙연산**: 덧셈(`+`), 뺄셈(`-`), 곱셈(`×`), 나눗셈(`÷`)
- **편의 기능**: 백스페이스(`⌫`), 초기화(`AC`), 부호 반전(`±`), 백분율(`%`)
- **키보드 지원**: 숫자 키패드 및 기본 키보드로 바로 입력 가능 (`Enter`, `Esc`, `Backspace` 등)
- **계산 기록(히스토리)**: 이전 계산 내역을 확인하고, 클릭 시 해당 결과를 불러와 재사용 가능
- **0으로 나누기 방지 및 부동소수점 오차 보정**

---

## 2. 터미널(PowerShell) 콘솔 계산기
터미널 환경에서 가볍게 텍스트로 수식을 계산할 수 있는 스크립트입니다.

### 실행 방법
터미널(PowerShell)에서 아래 명령어를 실행합니다:
```powershell
powershell -ExecutionPolicy Bypass -File .\calculator.ps1
```

### 기능
- 대화형으로 수식(`12 + 4 * 3` 등)을 입력하면 즉시 결과 출력
- 괄호 및 연산자 우선순위 자동 처리
- 안전한 입력값 검증 (숫자 및 사칙연산 기호 외 차단)
- `q` 또는 `exit` 입력 시 종료
